Memulai

Dari nol sampai layout aplikasi berjalan: memasang paket, memuat style layer, lalu menyusun shell wui-app — topbar, sidenav, dan wui-page.

Nama paket yang direncanakan: @wajek/wui@20.0 — nomor mayor mengikuti Angular 20. Paketnya satu: komponen Angular dan style layer dikirim bersama (SCSS-nya didaftarkan sebagai asset di ng-package.json), jadi tidak ada paket CSS terpisah yang versinya harus dijaga sendiri.

1. Instalasi

Satu perintah. @angular/cdk ditulis eksplisit karena statusnya peer dependency: npm 7+ sebenarnya memasangnya otomatis, tapi menuliskannya membuat versi yang benar-benar dipakai aplikasi jadi terlihat. 

npm install @wajek/wui@20.0 @angular/cdk@^20.2.0
Paket Versi Kenapa
@wajek/wui 20.0 Komponen Angular + style layer — satu paket.
@angular/cdk ^20.2.0 Dipakai dialog (overlay) dan wui-page (focus trap). Wajib dipasang sendiri, bukan dependensi transitif.
@angular/core, common, platform-browser ^20.3.0 Peer wajib — di aplikasi Angular 20.3 sudah ada.

Tidak ada langkah build tambahan, CLI, atau skematik. Semua API diekspor dari akar paket: import { WuiApp, WuiTopbar, WuiSidenav, WuiPage } from '@wajek/wui';

2. Include style

Style layer dimuat manual dari styles.scss: satu baris, tanpa import CSS terpisah dan tanpa auto-inject. Karena aplikasi yang menentukan kapan memuatnya, urutan style aplikasi tetap bisa diatur. 

// src/styles.scss — warna dari export Material Theme Builder
    @use './theme/wui-schemes' as theme;
    @use '@wajek/wui/scss/wui.scss' with ($wui-schemes: theme.$wui-schemes);

Konfigurasi di dalam with (...) bersifat opsional — tanpa itu library memakai nilai bawaan. Semuanya dibaca saat compile, jadi mengubahnya butuh rebuild; nilai yang perlu berubah saat runtime diatur lewat CSS variable (lihat di bawah).

Opsi Isi
$wui-schemes Inti konfigurasi warna: peran untuk light & dark. Bawaannya skema M3 penuh (45 peran) hasil export Material Theme Builder; nilainya boleh (palet, tone), warna langsung, atau CSS apa pun.
$wui-palette Skala palet yang di-emit (--wui-color-<palet>-<tone>). Bawaan false: palet cuma data, jadi nama bawaan yang sama dengan nama peran M3 tidak pernah sampai ke CSS.
$wui-palettes-extra Palet milik aplikasi, bentuk MTB: satu skala tone absolut 0–100 untuk kedua mode. Perlu hanya kalau mau memakai peran (palet, tone) atau meng-emit skalanya.

Urutan level di dalam wui.scss

Satu hal yang perlu diingat dari struktur SCSS-nya: urutannya disengaja. Itulah cara utilitas menang atas komponen tanpa !important.

  1. abstracts — token, fungsi, mixin. Tidak menghasilkan CSS.
  2. base — reset, tipografi, layout dasar.
  3. themes — palet & peran warna ke CSS variable (:root, mode gelap).
  4. components — tombol, sidenav, dialog, tabel, form, …
  5. layout — container & grid.
  6. utilities — spacing, gap, flex. Paling akhir, jadi bisa menimpa apa pun di atasnya.

Menyetel nilai tanpa rebuild

Angka desain yang berguna keluar sebagai CSS variable, jadi aplikasi bisa menimpanya langsung di :root-nya sendiri — tanpa menyentuh paket dan tanpa build ulang. 

// src/styles.scss, setelah baris @use di atas
    :root {
    --wui-color-primary: #4b2ea8;    // peran warna
    --wui-space-4: 1.25rem;          // skala spasi
    --wui-sidenav-width: 18rem;      // ukuran komponen
    }

3. Layout aplikasi

Susunannya cuma satu komponen: <wui-app> dipasang sekali di root, lalu isinya diproyeksikan ke tempat yang tepat. Topbar ke baris atas, sidenav ke kolom kiri, sisanya (termasuk <router-outlet>) ke area konten yang menggulir. 

<!-- src/app/app.html -->
    <wui-app>
    <wui-topbar>…</wui-topbar>
    <wui-sidenav id="app-sidenav">…</wui-sidenav>
    <router-outlet />
    </wui-app>
Yang ditulis di dalamnya Ditempatkan di
<wui-topbar> Baris atas, tinggi tetap 4rem, lebar penuh.
<wui-sidenav> Kolom kiri di dalam .wui-layout.
apa pun selain keduanya Area konten (.wui-layout-content) — biasanya <router-outlet />.

3.1 Topbar

Topbar tidak punya API: ia baris flex dengan tiga slot class, dan isinya ditentukan aplikasi. Jadi tombol menu di kiri dan aksi akun di kanan tidak perlu "dipinjamkan" dari library. 

<wui-topbar>
    <div class="wui-topbar-leading">
        <button wuiButton iconOnly variant="text" (click)="toggleMini()">
        <wui-icon icon="menu" />
        </button>
    </div>

    <div class="wui-topbar-content">Nama aplikasi</div>

    <div class="wui-topbar-trailing">
        <button wuiButton iconOnly variant="text">
        <wui-icon icon="account-circle" />
        </button>
    </div>
    </wui-topbar>
Slot Perilakunya
.wui-topbar-leading Menempel kiri, tidak melebar (flex: 0 0 auto).
.wui-topbar-content Mengisi sisa lebar + padding kiri-kanan 12px — tempat judul halaman.
.wui-topbar-trailing Menempel kanan, tidak melebar.

<wui-icon> tidak membawa data ikonnya sendiri. Daftarkan dulu sekali di provider aplikasi: provideIcons({ name: 'menu', path: mdiMenu }) (@mdi/js), lalu pakai lewat icon="menu".

3.2 Sidenav

Sidenav selalu punya markup untuk dua mode sekaligus: mode ringkas (wuiSidenavMini) dan mode penuh (wuiSidenavFull). Yang tampil mengikuti state-nya, jadi lebar panel bisa berubah tanpa memindahkan DOM. 

<wui-sidenav id="app-sidenav" initialState="open">
    <!-- Mode ringkas: rail, biasanya hanya ikon -->
    <nav wuiSidenavMini>
        <div wuiSidenavBody>
        <a wuiSidenavItem routerLink="/home" routerLinkActive="is-active">
            <wui-icon icon="home" />
        </a>
        </div>
        <div wuiSidenavFooter>
        <a wuiSidenavItem routerLink="/setting"><wui-icon icon="settings" /></a>
        </div>
    </nav>

    <!-- Mode penuh: ikon + label -->
    <nav wuiSidenavFull>
        <div wuiSidenavBody>
        <a wuiSidenavItem routerLink="/home" routerLinkActive="is-active">
            <wui-icon icon="home" /> Beranda
        </a>

        <div wuiSidenavSubheader>Pengaturan</div>

        <a wuiSidenavItem routerLink="/setting">
            <wui-icon icon="settings" /> Preferensi
        </a>
        </div>
        <div wuiSidenavFooter>
        <a wuiSidenavItem routerLink="/about">Tentang</a>
        </div>
    </nav>
    </wui-sidenav>
Directive Untuk apa
[wuiSidenavMini] / [wuiSidenavFull] Blok markup per mode. Salah satu akan terlihat sesuai state sidenav.
[wuiSidenavBody] Area isi: setinggi sisa panel dan menggulir sendiri kalau daftarnya panjang.
[wuiSidenavFooter] Area bawah: selalu menempel di ujung bawah, tidak ikut tergulir. Garis pemisahnya sudah digambar oleh style-nya.
[wuiSidenavItem] Mengubah tombol/tautan jadi item navigasi: lebar penuh, sudut rata, rata kiri, dan mendukung state aktif .is-active.
[wuiSidenavSubheader] Judul kategori menu di dalam daftar.
[wuiSidenavDivider] Garis pemisah antar grup menu (opsional — footer sudah punya garis sendiri).

id itu wajib dan jadi kunci state di WuiSidenavService. Artinya siapa pun boleh mengubah sidenav dari luar — tombol di topbar maupun halaman aktif — dan tidak ada state yang perlu diteruskan manual: 

private readonly sidenav = inject(WuiSidenavService);

    toggle()     { this.sidenav.toggle('app-sidenav');     }  // open ↔ close
    toggleMini() { this.sidenav.toggleMini('app-sidenav'); }  // open ↔ mini

    // Reaktif kalau perlu ditampilkan/di-baca di template:
    readonly state = this.sidenav.state('app-sidenav');      // Signal<WuiSidenavState>
State Tampilan
open (bawaan) Panel penuh, 16rem.
mini Rail ringkas, 4rem — biasanya hanya ikon.
close Menyusut ke 0; aria & fokus aman karena elemennya tetap ada di DOM.

3.3 Halaman: wui-page

Halaman tidak ditulis langsung sebagai isi router-outlet, tapi di dalam <wui-page>. Komponen ini yang menyediakan area konten yang menggulir, dan hanya bagian itulah yang overflow-y: auto — topbar dan sidenav tetap diam. 

<!-- template halaman -->
    <wui-page>
    <div wuiPageContent wuiScrollbar>
        <h1>Judul halaman</h1>
        …isi halaman…
    </div>
    </wui-page>

Kalau satu halaman perlu topbar atau sidenav-nya sendiri, cukup ditulis di dalam <wui-page> sebelum [wuiPageContent] — komponen itu juga memproyeksikan <wui-topbar> dan <wui-sidenav>.

3.4 Memasang halaman dari kode

Halaman ditumpuk oleh WuiPageService ke overlay milik <wui-app>. Polanya: kirim template halaman saat komponennya dibuat. 

@Component({ selector: 'app-setting.page', imports: [WuiPage] })
    export class SettingPage implements OnInit {
    private readonly pages = inject(WuiPageService);
    private readonly page = viewChild.required<TemplateRef<unknown>>('page');

    ngOnInit(): void {
        this.pages.replace(this.page(), { variant: 'full' });
    }
    }
API Kapan dipakai
replace(tpl, opsi) Halaman yang menggantikan tampilan sekarang (kasus paling umum, termasuk di halaman ini) — kedalaman tumpukan tidak bertambah.
push(tpl, opsi) Halaman baru di atas yang sekarang — mis. form detail dari daftar, lalu pengguna menutupnya dan kembali.
close(ref) / closeTop() / closeAll() Menutup halaman. Idempoten, jadi aman dipanggil berkali-kali.
variant: 'full' | 'modal' full menutup penuh area; modal transparan + backdrop dan bisa ditutup lewat ESC/backdrop.

Yang sudah ditangani otomatis begitu halaman berjalan lewat service: hanya page teratas yang menerima fokus dan klik, isi di bawahnya diberi aria-hidden, dan fokus kembali ke elemen pemicu saat halaman ditutup.

4. Urutan pemasangan

Ringkasan kelima langkahnya, dari nol sampai aplikasi punya shell dan halaman.

  1. Pasang paket: npm install @wajek/wui@20.0 @angular/cdk@^20.2.0
  2. Muat style layer: @use '@wajek/wui/scss/wui.scss' with (…); di src/styles.scss.
  3. Daftarkan ikon sekali di provider: provideIcons(…) — wajib kalau memakai <wui-icon>.
  4. Susun shell di app.html: <wui-app> + topbar + sidenav + <router-outlet />.
  5. Bungkus tiap halaman dengan <wui-page> + .wui-page-content, lalu pasang lewat WuiPageService.replace().

Halaman lain di menu samping mendokumentasikan tiap bagian lebih dalam: Tipografi untuk teks & peran ukuran, lalu halaman per komponen (button, dialog, form, sidenav, table, layout).
