WUI Sidenav Specimen & Dokumentasi

Komponen <wui-sidenav> dan kumpulan directive pelengkap di @wajek/wui. Mendukung transisi tiga-state (open, mini, close) yang dikendalikan secara reaktif oleh WuiSidenavService, dengan dukungan mode Rail / Mini dan adaptasi tema otomatis.

Sidenav didesain fleksibel: ia tidak memaksakan isi menu, namun menyediakan kumpulan attribute directive resmi — wuiSidenavMini, wuiSidenavFull, wuiSidenavBody, wuiSidenavFooter, wuiSidenavItem, wuiSidenavDivider, wuiSidenavSubheader — untuk membangun panel navigasi Material 3 yang siap pakai. Setiap mode (mini maupun full) terbagi dua area: wuiSidenavBody mengisi tinggi yang tersisa dan menggulir sendiri, sedangkan wuiSidenavFooter selalu menempel di ujung bawah.

1. Interactive Playground

Uji perilaku interaktif sidenav secara langsung. Perhatikan transisi animasi mulus (*cross-fade*) antara konten lengkap dan konten ringkas (ikon saja), serta amati perubahan signal reaktif secara real-time.

Ketika sidenav melebar atau menyusut, layout halaman di sekitarnya secara otomatis bergeser mengikuti alur flex layout (flex: 0 0 auto).

Garis batas samping digambar menggunakan box-shadow: inset -1px 0 0 var(--wui-color-outline), sehingga saat ditutup habis, tidak ada sisa garis border 1px yang tertinggal.

2. Anatomi Komponen & Directives

Daftar directive modular yang tersedia di bawah modul @wajek/wui:

Selector Host Class Elemen Target Keterangan
<wui-sidenav id="..."> .wui-sidenav Custom Element Kontainer induk sidenav. Mengelola state via WuiSidenavService.
[wuiSidenavBody] .wui-sidenav-body <div> / <nav> Area isi: mengisi tinggi yang tersisa dan menggulir sendiri (overflow-y: auto). Ditaruh di dalam blok mini/full.
[wuiSidenavFooter] .wui-sidenav-footer <div> Area bawah: selalu menempel di ujung bawah sidenav, tidak ikut tergulir. Garis pemisah di atasnya digambar style layer, jadi tidak perlu <hr wuiSidenavDivider> sebelum item terakhir.
[wuiSidenavFull] .wui-sidenav-full-content <nav> / <div> Konten mode penuh (ikon + label teks). Meluncur keluar saat mode mini.
[wuiSidenavMini] .wui-sidenav-mini-content <nav> / <div> Konten mode ringkas / rail (hanya ikon). Meluncur masuk saat mode mini.
[wuiSidenavItem] .wui-sidenav-item <a> / <button> Mengubah tombol menjadi berlebar 100%, tanpa radius sudut, dan rata kiri (rata tengah di mode mini).
[wuiSidenavDivider] .wui-sidenav-divider <hr> Garis horizontal tipis pemisah grup menu dengan warna adaptif.
[wuiSidenavSubheader] .wui-sidenav-subheader <div> / <span> Label judul kategori seksi berhuruf kapital, kontras tinggi di Light & Dark mode.

3. API WuiSidenavService

Service singleton yang mengelola status setiap sidenav menggunakan Angular Signals.

Method / Property Return Type Penjelasan
open(id: string) void Membuka sidenav ke mode penuh (open).
mini(id: string) void Mengecilkan sidenav ke mode ringkas (mini).
close(id: string) void Menutup sidenav sampai lebar 0 (close).
toggle(id: string) void Membalikkan state open ↔ close.
toggleMini(id: string) void Membalikkan state mini ↔ open.
state(id: string) Signal<WuiSidenavState> Membaca state aktif saat ini ('open' | 'mini' | 'close').
isOpen(id: string) Signal<boolean> Bernilai true jika state sama dengan 'open'.
isMini(id: string) Signal<boolean> Bernilai true jika state sama dengan 'mini'.
isClosed(id: string) Signal<boolean> Bernilai true jika state sama dengan 'close'.

4. Contoh Penggunaan Lengkap

Markup standar untuk menerapkan sidenav dua mode di aplikasi Anda: 

<wui-sidenav id="app-sidenav">
  <!-- Mode Mini: Hanya Ikon -->
  <nav wuiSidenavMini>
    <div wuiSidenavBody>
      <a wuiButton variant="text" size="lg" routerLink="/home" routerLinkActive="is-active" wuiSidenavItem aria-label="Beranda">
        <wui-icon icon="home"></wui-icon>
      </a>
    </div>

    <div wuiSidenavFooter>
      <a wuiButton variant="text" size="lg" routerLink="/setting" routerLinkActive="is-active" wuiSidenavItem aria-label="Pengaturan">
        <wui-icon icon="settings"></wui-icon>
      </a>
    </div>
  </nav>

  <!-- Mode Penuh: Ikon + Label Teks -->
  <nav wuiSidenavFull>
    <div wuiSidenavBody>
      <a wuiButton variant="text" size="lg" routerLink="/home" routerLinkActive="is-active" wuiSidenavItem>
        <wui-icon icon="home"></wui-icon>
        Beranda
      </a>
      <div wuiSidenavSubheader>PENGATURAN</div>
    </div>

    <div wuiSidenavFooter>
      <a wuiButton variant="text" size="lg" routerLink="/setting" routerLinkActive="is-active" wuiSidenavItem>
        <wui-icon icon="settings"></wui-icon>
        Pengaturan
      </a>
    </div>
  </nav>
</wui-sidenav>

5. Design Tokens & Variabel CSS

CSS Variables yang mengatur dimensi dan animasi Sidenav:

Variabel CSS Nilai Default Deskripsi
--wui-sidenav-width 16rem (256px) Lebar Sidenav saat berada pada mode open.
--wui-sidenav-mini-width 4rem (64px) Lebar Sidenav saat berada pada mode mini (rail).
--wui-motion-duration-base 400ms Durasi transisi perubahan lebar dan geser konten.
--wui-motion-easing-standard cubic-bezier(0.2, 0, 0, 1) Kurva percepatan standar Material 3.
