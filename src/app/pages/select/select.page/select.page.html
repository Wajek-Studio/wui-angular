WuiSelect

<wui-select wuiInput [value] [placeholder] [disabled] (valueChange)>

Komponen dropdown utama. Wajib disandingkan dengan directive wuiInput agar styling dari wui-form-field dan properti ARIA terhubung dengan baik.

Properti & Event

NamaTipeKeterangan
[value]unknownNilai opsi yang saat ini terpilih.
[placeholder]stringTeks yang ditampilkan saat select difokus namun belum ada nilai.
[disabled]booleanMenonaktifkan interaksi select.
(valueChange)EventEmitter<unknown>Event saat opsi baru dipilih oleh pengguna.

WuiOption

<wui-option [value] [disabled] [typeaheadLabel]>

Item pilihan di dalam panel dropdown.

Properti

NamaTipeKeterangan
[value]unknownNilai programatik opsi. Jika kosong, isi teks dari child element akan dipakai.
[disabled]booleanMencegah opsi dipilih. Navigasi keyboard akan melewati opsi ini.
[typeaheadLabel]stringTeks yang ditampilkan di select saat terpilih, dan digunakan untuk navigasi keyboard. Wajib jika opsi berisi elemen HTML kompleks.

Direktif

Simbol (Import)Keterangan
WuiSelectKomponen dropdown <wui-select>
WuiOptionItem pilihan <wui-option>
WuiFormFieldKomponen wrapper parent <wui-form-field>
WuiLabelDirective floating label <label wuiLabel>
WuiInputDirective penghubung wuiInput, wajib disematkan pada <wui-select>
