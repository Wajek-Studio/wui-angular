Flexbox

Rangkaian utilitas flexbox komprehensif untuk mengatur tata letak 1-dimensi secara responsif tanpa menulis CSS kustom. Setiap utilitas memiliki varian responsif (contoh: .wui-flex-md-row).

1. Direction & Wrap

ClassKeterangan
.wui-flex, .wui-flex-inline Menerapkan display: flex atau inline-flex.
.wui-flex-row, .wui-flex-row-reverse Mengatur arah flex menjadi horizontal.
.wui-flex-col, .wui-flex-col-reverse Mengatur arah flex menjadi vertikal (kolom).
.wui-flex-wrap, .wui-flex-nowrap Mengatur pembungkusan item jika melebihi ruang.

2. Justify Content (Sumbu Utama)

ClassKeterangan
.wui-justify-content-[value] Nilai: start, end, center, between, around, evenly.

3. Align Items & Align Self (Sumbu Silang)

ClassKeterangan
.wui-align-items-[value] Perataan untuk semua anak flex. Nilai: start, end, center, baseline, stretch.
.wui-align-self-[value] Menimpa perataan pada satu item. Nilai sama seperti di atas.
.wui-align-content-[value] Perataan pembungkusan garis (saat wrap).

4. Flex Fill, Grow & Order

ClassKeterangan
.wui-flex-fill Mengisi sisa ruang secara proporsional (flex: 1 1 auto).
.wui-flex-grow-0, .wui-flex-grow-1 Mengatur kemampuan item untuk membesar.
.wui-flex-shrink-0, .wui-flex-shrink-1 Mengatur kemampuan item untuk menyusut.
.wui-order-[value] Urutan visual item. Nilai: 0..5, first, last.

5. Responsive Flex Layout

Class BreakpointKeterangan
.wui-[flex-property]-[bp]-[value] Tambahkan sisipan breakpoint (sm, md, lg, xl, xxl). Contoh: .wui-flex-md-row, .wui-justify-content-lg-between, .wui-order-xl-1.
