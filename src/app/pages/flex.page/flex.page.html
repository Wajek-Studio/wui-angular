Flexbox Utilities

Rangkaian utilitas flexbox komprehensif di @wajek/wui (arah, wrap, perataan, distribusi ruang, dan urutan) untuk mengatur tata letak 1-dimensi secara responsif tanpa menulis CSS kustom.

Utilitas flexbox datang dari projects/wui/scss/utilities/_flex.scss (Level 6). Format nama mengikuti konvensi Bootstrap dengan prefix wui- (seperti .wui-d-flex, .wui-justify-content-between, .wui-align-items-center). Setiap utilitas memiliki varian responsif -<bp> (contoh: .wui-flex-md-row, .wui-justify-content-lg-end).

1. Direction & Wrap

Atur arah aliran anak flex dengan .wui-flex-row, .wui-flex-row-reverse, .wui-flex-column, .wui-flex-column-reverse, serta pembungkusan dengan .wui-flex-wrap atau .wui-flex-nowrap.
