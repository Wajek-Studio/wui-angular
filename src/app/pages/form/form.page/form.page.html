Form Field

Usage

WuiFormField

<wui-form-field [variant] [hint] [error]>

Wadah induk yang mengelola label, kontrol, hint, dan pesan error. Saat [error] berisi nilai, warna beralih ke error dan aria-invalid="true" diterapkan otomatis.

Properti

PropertiTipeDefaultKeterangan
variant 'outlined' | 'filled' 'outlined' Varian visual: border penuh atau latar solid dengan garis bawah
hint string '' Teks petunjuk di bawah input. Disembunyikan otomatis saat error memiliki nilai
error string '' Pesan error. Mengisi properti ini mengaktifkan state error dan menyembunyikan hint
id string auto ID kontrol. Jika dikosongkan, WUI membuatkan ID unik otomatis

WuiInput

[wuiInput]

Directive yang ditempelkan ke kontrol native. Menerapkan styling, mengelola atribut ARIA, dan menghubungkan kontrol ke <wui-form-field> induknya.

Target yang Didukung

ElemenContoh
<input><input wuiInput type="text" />
<textarea><textarea wuiInput></textarea>
<wui-select><wui-select wuiInput>…</wui-select>

Modifier
