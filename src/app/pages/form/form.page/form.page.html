Forms & Validation

<wui-form-field> menyusun label mengapung, kontrol input native atau kustom (seperti wui-select), serta pesan petunjuk (hint) dan kesalahan (error). Terintegrasi penuh dengan Reactive Forms bawaan Angular tanpa dependensi pihak ketiga.

Prinsip Desain: Label adalah elemen <label> asli yang mengapung otomatis saat kontrol difokus atau telah terisi. Saat [error] memiliki nilai, pesan error otomatis menggantikan hint, kontrol ditandai aria-invalid="true", dan warna beralih ke peran semantik error.

💡
Penting — Syarat Import Direktif Form:

Form di @wajek/wui dirancang modular berbasis directive native. Untuk bekerja sempurna, komponen Anda wajib mengimpor tiga direktif utama:

  • WuiFormField — Komponen pembungkus kontainer field (<wui-form-field>).
  • WuiLabel — Directive label mengapung (<label wuiLabel>).
  • WuiInput — Directive styling & a11y kontrol (<input wuiInput>, <textarea wuiInput>, <wui-select wuiInput>).

⚠️ Jika Anda hanya mengimpor WuiFormField ke dalam imports: [...], directive wuiLabel dan wuiInput tidak akan aktif sehingga label tidak mengapung dan styling kontrol tidak teraplikasi.

8. Ringkasan & Tabel Referensi Direktif

Daftar seluruh komponen dan direktif yang disediakan @wajek/wui untuk membangun form:

A. Direktif & Komponen yang Tersedia

Nama Simbol (Import) Selector Template Target Elemen Fungsi & Tanggung Jawab
WuiFormField wui-form-field Komponen Wrapper Wadah induk yang mengelola penempatan label, kontrol, petunjuk (hint), dan pesan kesalahan (error).
WuiLabel label[wuiLabel] <label> asli Menerapkan animasi floating label saat kontrol difokus atau berisi teks, serta menautkan atribut for otomatis.
WuiInput [wuiInput] <input>, <textarea>, <wui-select> Menerapkan kelas styling .wui-input, mengelola placeholder pengapung, serta menautkan atribut ARIA (aria-describedby, aria-invalid).
WuiSelect wui-select Komponen Dropdown Kontrol combobox kustom native WUI yang kompatibel penuh di dalam <wui-form-field>.
WuiOption wui-option Komponen Pilihan Item pilihan data di dalam panel dropdown <wui-select>.

B. Properti Input pada <wui-form-field>

Input Property Tipe Data Default Keterangan
variant 'outlined' | 'filled' 'outlined' Varian visual field: outlined (border penuh sekeliling) atau filled (latar solid dengan penegas bawah).
hint string '' Teks petunjuk pengisian netral di bawah kotak input. Otomatis disembunyikan saat error memiliki nilai.
error string '' Pesan validasi gagal. Mengisi properti ini akan mengubah warna field ke tema error dan menyetel aria-invalid="true".
id string '' ID kontrol spesifik (opsional). Jika dikosongkan, WUI akan membuatkan ID unik otomatis.
