Table — WuiTable

Komponen dan directive tabel native bergaya Material 3. Mengadopsi visual presisi dari wui-angular-17.x dengan sistem token adaptif untuk tema terang dan gelap.

Filosofi Native: Directive wuiTable dipasang langsung pada elemen <table> standar HTML tanpa mengganti tag elemen, sehingga aksesibilitas (caption, header scope, navigating cell) dan fleksibilitas markup tetap 100% utuh.

1. Interactive Playground

Uji efek visual hover, baris selang-seling alternate, dan mode dense secara langsung. Perhatikan bahwa baris header, baris data, dan baris footer memiliki pembatas yang rapi serta kolom aksi mengecil pas selebar tombol.

Gunakan .wui-table-col--sticky-left dan .wui-table-col--sticky-right di dalam kontainer wuiTableResponsive untuk menjaga kolom identitas dan kolom aksi tetap terlihat saat pengguna menggeser tabel ke samping.

3. Referensi Directive & Utility

Directive / Class Tipe / Nilai Keterangan
wuiTable / .wui-table Directive / CSS Class Dipasang pada tag <table> untuk menerapkan gaya dasar data table.
[hover] / .wui-table-hover boolean Mengaktifkan efek sorot warna halus saat kursor mengarah ke baris tbody tr.
[dense] / .wui-table--dense boolean Mengurangi tinggi baris dan padding untuk menampilkan data lebih padat.
[alternate] / .wui-table--alternate boolean Mengaktifkan latar belang-belang tipis (zebra-striping) pada baris genap.
wuiTableResponsive Directive / Container Kontainer pembungkus tabel yang mengizinkan scroll horizontal saat melebihi lebar layar.
.wui-table-col--action CSS Class (pada th / td) Menyetel lebar sel ke ukuran minimum agar pas membungkus tombol aksi atau ikon saja.
.wui-table-col--sticky-left / .wui-table-col--sticky-right CSS Class (pada th / td) Mengunci kolom di sisi kiri atau kanan saat tabel digeser horizontal. Otomatis memakai warna surface.
.wui-table-row--no-border CSS Class (pada tr) Menghilangkan garis bawah pemisah pada baris tertentu.
wui-pagination Component Komponen pagination mandiri untuk navigasi tabel. Menggunakan tombol wuiButton size="sm" iconOnly variant="text".
[(page)] model<number> Halaman aktif (1-indexed). Mendukung two-way data binding.
[count] number Total seluruh baris data.
[limit] number Jumlah baris data per halaman (default 10).
[loading] boolean Menampilkan teks 'Memuat...' dan menonaktifkan tombol sementara saat mengambil data dari server.
