Spacing & Margin / Padding Utilities

Rangkaian utilitas spasi di @wajek/wui (margin, padding, auto-margin, dan gap) yang terhubung langsung ke skala token desain --wui-space-*.

Utilitas spacing datang dari projects/wui/scss/utilities/_spacing.scss dan _gap.scss. Nilai skala langkah: 0 (0), 1 (0.25rem = 4px), 2 (0.5rem = 8px), 3 (1rem = 16px), 4 (1.5rem = 24px), dan 5 (3rem = 48px). Dukungan arah: t (top), b (bottom), s (start/kiri LTR), e (end/kanan LTR), x (horizontal), y (vertical).

1. Margin Utilities

Tambahkan jarak luar di sekeliling atau pada sisi tertentu elemen menggunakan .wui-m-*, .wui-mt-*, .wui-mb-*, .wui-ms-*, .wui-me-*, .wui-mx-*, dan .wui-my-*.

2. Padding Utilities

Tambahkan bantalan ruang dalam elemen menggunakan .wui-p-* atau per arah spesifik seperti .wui-pt-*, .wui-pb-*, .wui-ps-*, .wui-pe-*, .wui-px-*, dan .wui-py-*.

3. Auto Margin Centering & Flex Push

Auto margin sangat berguna untuk memusatkan elemen blok secara horizontal (.wui-mx-auto) atau mendorong grup elemen navigasi ke sisi kanan flexbox (.wui-ms-auto).

4. Gap Utilities

Utilitas .wui-gap-col-* dan .wui-gap-row-* memberikan jarak konsisten antara anak elemen flex atau sel grid tanpa trik margin negatif. (Perhatikan: tidak ada class gabungan wui-gap-*, Anda harus mengatur spesifik untuk kolom dan baris).

ClassKeterangan

.wui-mx-[0..5], .wui-mx-auto Margin sumbu X (kiri & kanan).
.wui-my-[0..5] Margin sumbu Y (atas & bawah).
.wui-mt-[0..5], .wui-mt-auto Margin Top (atas).
.wui-mb-[0..5], .wui-mb-auto Margin Bottom (bawah).
.wui-ms-[0..5], .wui-ms-auto Margin Start (kiri pada LTR).
.wui-me-[0..5], .wui-me-auto Margin End (kanan pada LTR).

B. Padding

ClassKeterangan
.wui-p-[0..5] Padding ke semua arah.
.wui-px-[0..5] Padding sumbu X (kiri & kanan).
.wui-py-[0..5] Padding sumbu Y (atas & bawah).
.wui-pt-[0..5] Padding Top (atas).
.wui-pb-[0..5] Padding Bottom (bawah).
.wui-ps-[0..5] Padding Start (kiri pada LTR).
.wui-pe-[0..5] Padding End (kanan pada LTR).

C. Gap

ClassKeterangan
.wui-gap-row-[0..5] Mengatur jarak vertikal antar baris untuk semua ukuran layar.
.wui-gap-row-[bp]-[0..5] Mengatur jarak vertikal antar baris mulai breakpoint bp ke atas.
.wui-gap-col-[0..5] Mengatur jarak horizontal antar kolom untuk semua ukuran layar.
.wui-gap-col-[bp]-[0..5] Mengatur jarak horizontal antar kolom mulai breakpoint bp ke atas.
