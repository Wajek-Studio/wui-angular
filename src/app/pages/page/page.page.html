Page

<wui-page> adalah shell halaman. Isi halaman dipasang ke dalam [wuiPageHost] melalui WuiPageService — tanpa routing. Mendukung halaman bertumpuk (nested) dan beberapa host sekaligus.

Showcase

WuiPageService

replace(template: TemplateRef<any>, hostname: string = 'main'): WuiPageRef<any>

Berfungsi untuk mengganti seluruh tumpukan halaman dengan halaman baru

Parameter

NAMA TIPE KETERANGAN
template TemplateRef<any> Template yang digunakan dalam tumpukan page.
hostname string Nama pagehost yang digunakan untuk display halaman
