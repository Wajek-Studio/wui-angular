Layout — Container, Grid & Flexbox

Sistem tata letak komprehensif di @wajek/wui: pembungkus terpusat (.wui-container), sistem kisi 12-kolom (.wui-row & .wui-col-*), serta rangkaian utilitas flexbox dan gap untuk merancang antarmuka responsif tanpa CSS kustom.

Primitif layout datang dari level layout/ dan utilities/ — class murni tanpa komponen Angular tambahan. Seluruh ukuran, lebar, dan jarak terhubung langsung ke token desain (_tokens.scss) dan CSS Variable bawaan WUI, mendukung breakpoint: sm (576px), md (768px), lg (992px), xl (1200px), dan xxl (1400px).

1. Container (Pembungkus Halaman)

Container membatasi lebar maksimal konten dan memusatkannya secara horizontal di tengah layar. Gutter bawaan (1.5rem) memastikan konten tidak menyentuh tepi layar di perangkat mobile.

Batas container aktif saat ini: batas sejak md (≥768px) aktif
.wui-container Lebar 100% di bawah 768px, margin tetap 3rem sejak md, dan berhenti di cap 1200px.

Simulasi Perbandingan Varian Container

6. Ringkasan & Tabel Referensi Kelas

Daftar seluruh utility class layout yang tersedia langsung di @wajek/wui:

Kategori Class Deskripsi & Penggunaan
Container .wui-container Membatasi lebar maksimal secara bertingkat dan memusatkan konten (cap 1200px).
Container .wui-container-fluid Lebar penuh 100% di segala ukuran layar tanpa batas maksimum.
Grid .wui-row Container CSS Grid 12-kolom (grid-template-columns: repeat(12, minmax(0, 1fr))).
Grid .wui-col-{1-12} Span kolom dasar (misal .wui-col-6 untuk 50% lebar).
Grid .wui-col-{bp}-{1-12} Span kolom responsif per breakpoint (sm, md, lg, xl, xxl).
Flex Display .wui-d-flex, .wui-d-inline-flex Mengaktifkan mode flexbox atau inline-flexbox.
Flex Direction .wui-flex-row, .wui-flex-column, *-reverse Mengatur arah sumbu utama item (tersedia juga varian breakpoint misal .wui-flex-md-row).
Flex Justify .wui-justify-content-{start|center|end|between|around|evenly} Perataan item di sepanjang sumbu utama.
Flex Align .wui-align-items-{start|center|end|baseline|stretch} Perataan vertikal item di sepanjang sumbu silang.
Flex Children .wui-flex-fill, .wui-flex-grow-{0|1}, .wui-flex-shrink-{0|1} Mengontrol bagaimana anak flex mengisi ruang dan merespons peregangan.
Gap .wui-gap-{0-5}, .wui-row-gap-*, .wui-column-gap-* Jarak antar elemen grid atau flexbox terikat ke --wui-space-*.

7. Catatan Arsitektur

  • Tanpa JavaScript: Seluruh layout dan grid dibangun murni dengan CSS Grid & Flexbox native, membuat rendering sangat cepat tanpa overhead Angular runtime.
  • Urutan Layer SCSS WUI: abstracts → base → themes → components → layout → utilities. Kelas di layout/ (container, row, col) dapat menimpa komponen tanpa !important, dan kelas di utilities/ (flex, gap, spacing) memiliki spesifisitas akhir yang menang.
  • Integrasi Token Desain: Semua breakpoint, batas container, dan skala gap bersumber dari projects/wui/scss/abstracts/_tokens.scss, menjamin konsistensi visual di seluruh aplikasi.
