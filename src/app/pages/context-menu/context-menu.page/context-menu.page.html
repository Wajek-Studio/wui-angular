WUI Menu Konteks

Menu konteks dibuka lewat klik kanan (atau long-press di sentuh) pada sebuah elemen: [wuiContextMenu] memegang template menunya, dan isi menu ditulis dengan <wui-menu> + <wui-menu-item>. Perilaku keyboard (panah, Home/End, type-ahead, Enter) datang dari @angular/cdk/menu.

Panelnya memperlakukan dirinya seperti panel <wui-select>: ada backdrop transparan, jadi elemen di belakang menu tidak bereaksi dan halaman tidak ikut bergulir; Esc menutup satu tingkat saja — menunya, bukan dialog yang membungkusnya.
