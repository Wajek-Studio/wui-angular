WUI Menu Konteks

Menu konteks dibuka lewat klik kanan (atau long-press di sentuh) pada sebuah elemen: [wuiContextMenu] memegang template menunya, dan isi menu ditulis dengan <wui-menu> + <wui-menu-item>. Perilaku keyboard (panah, Home/End, type-ahead, Enter) datang dari @angular/cdk/menu.

Panelnya memperlakukan dirinya seperti panel <wui-select>: ada backdrop transparan, jadi elemen di belakang menu tidak bereaksi dan halaman tidak ikut bergulir; Esc menutup satu tingkat saja — menunya, bukan dialog yang membungkusnya.

Aksi terakhir: {{ aksiTerakhir() }}

1. Pemicu tombol

Klik kanan pada tombol. Item terakhir nonaktif (boleh dilewati panah, tidak boleh diaktifkan), dan ada satu pemisah serta satu item dengan label type-ahead berbeda dari teksnya.

2. Baris tabel dengan data konteks

Tiap baris memakai menu yang sama, tetapi mengirim datanya sendiri lewat [wuiContextMenuData] — template menu membacanya dengan <ng-template #menu let-data>.

3. Di dalam dialog

Buka dialog, lalu klik kanan di dalamnya. Satu kali Esc menutup menu saja; Esc berikutnya baru menutup dialognya.

4. Yang perlu diperiksa di F2

  • Esc & Tab menutup menu; fokus kembali ke elemen pemicu.
  • Panah atas/bawah berpindah item (item nonaktif tidak dilewati), Home/End ke ujung.
  • Mengetik huruf melompat sesuai typeaheadLabel.
  • Daftar panjang (menu dengan banyak item) menggulir sendiri tanpa menggeser halaman.
