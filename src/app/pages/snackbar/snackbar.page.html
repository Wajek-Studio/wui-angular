Snackbar

Pemberitahuan singkat (toast) di sudut bawah layar. Dikelola melalui WuiSnackbarService dengan animasi halus dan penutupan otomatis.

Usage

API Reference

WuiSnackbarService

Method Parameter Return Type Keterangan
open() message: string, duration = 3000 WuiSnackbarRef Membuka snackbar baru. Jika ada snackbar yang sedang aktif, instance lama otomatis ditutup (animasi keluar) terlebih dahulu.
close() - void Menutup paksa snackbar yang saat ini sedang aktif (jika ada).
