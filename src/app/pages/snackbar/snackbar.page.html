Snackbar

Pemberitahuan singkat (*toast*) non-intrusif di sudut kanan bawah layar yang mengonfirmasi bahwa suatu operasi telah selesai dijalankan. Dikelola melalui WuiSnackbarService dengan animasi masuk/keluar yang mulus, penutupan otomatis berbasis durasi waktu, serta tombol aksi manual.

Prinsip Desain Material 3: Snackbar menggunakan palet warna kebalikan (*inverse surface*) — --wui-color-inverse-surface untuk latar belakang dan --wui-color-inverse-on-surface untuk teks — sehingga secara visual selalu kontras tinggi terhadap warna permukaan utama di Light Mode maupun Dark Mode. Tombol aksi "OK" menggunakan warna aksen --wui-color-inverse-primary.

3. Ringkasan & Tabel Referensi API

Daftar service, reference, dan variabel desain yang disediakan oleh paket @wajek/wui untuk fitur snackbar:

A. WuiSnackbarService

Method Parameter Return Type Keterangan
open() message: string, duration = 3000 WuiSnackbarRef Membuka snackbar baru di pojok kanan bawah. Jika ada snackbar yang sedang terbuka, instance lama otomatis ditutup terlebih dahulu.
close() - void Menutup paksa snackbar yang saat ini sedang aktif (jika ada).

B. WuiSnackbarRef

Member Tipe Keterangan
dismiss() () => void Memulai animasi keluar (wui-snackbar--leaving), membersihkan CDK overlay, dan memancarkan sinyal afterDismissed.
afterDismissed Observable<void> Stream yang memicu notifikasi ketika proses dismiss dan pembersihan DOM telah selesai seutuhnya.
setDuration() (duration: number) => void Mengatur batas waktu timer otomatis (dalam milidetik). Jika disetel 0, snackbar tidak akan tertutup otomatis.

C. Token & Variabel Warna SCSS

CSS Variable Peran Warna Penggunaan di Komponen
--wui-color-inverse-surface Inverse Surface Warna latar belakang kotak snackbar (gelap di Light Mode, terang di Dark Mode).
--wui-color-inverse-on-surface Inverse On Surface Warna teks label snackbar untuk menjamin keterbacaan kontras tinggi.
--wui-color-inverse-primary Inverse Primary Warna tombol aksi penutup ("OK") di dalam kotak snackbar.

4. Catatan Teknis & Arsitektur

  • CDK Overlay Tanpa Backdrop: Snackbar dirender langsung ke dalam overlay container CDK pada level document.body tanpa memblokir klik atau scroll pada konten halaman di bawahnya.
  • Animasi Masuk & Keluar Halus: Dilengkapi dengan CSS keyframes wui-snackbar-enter (200ms ease-out) saat muncul dan wui-snackbar-leave (150ms ease-in) saat ditutup.
  • Pembersihan Timer Otomatis: Jika pengguna mengklik tombol "OK" sebelum timer habis, clearTimeout otomatis dipanggil untuk mencegah kebocoran memori (memory leak).
