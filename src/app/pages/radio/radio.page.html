Radio Button

Komponen <wui-radio-group> dan <wui-radio-button> untuk pemilihan opsi tunggal eksklusif. Terintegrasi penuh dengan [(ngModel)] maupun Reactive Forms.

Usage

Modifier

wui-radio-group

Properti Tipe Default Keterangan
[(ngModel)] any - Mengikat nilai terpilih dari grup. Mendukung two-way binding dan Reactive Forms.
disabled boolean false Menonaktifkan seluruh wui-radio-button yang ada di dalam grup ini.

wui-radio-button

Properti Tipe Default Keterangan
value any (Required) - Nilai spesifik untuk opsi ini. Jika diklik, wui-radio-group akan di-update dengan nilai ini.
