WUI Button Specimen

Tombol @wajek/wui mengikuti Material 3 — tiga varian warna dan empat ukuran. Dipasang sebagai atribut pada <button> native, sehingga disabled, type, dan perilaku form tetap milik browser.

State hover dan pressed dipaksa lewat class .is-hover / .is-pressed (pola yang sama dengan .is-dragged) supaya bisa dilihat tanpa menggerakkan mouse. Semua contoh di halaman ini memakai ukuran default md.

1. Filled variant="filled"

Varian default: container --wui-color-primary, label --wui-color-on-primary, elevasi 1 saat hover. Lapisan interaksinya dicampur ke warna container sehingga latar primary tidak tertimpa.

normal
.is-hover · layer on-primary 8% + elevasi 1
.is-pressed · layer on-primary 10%
disabled · container 12%, label 38%

2. Outlined variant="outlined"

Container transparan dengan border 1px --wui-color-outline, label --wui-color-primary. State layer-nya memakai peran primary sebagai lapisan transparan.

normal
.is-hover · layer primary 8%
.is-pressed · layer primary 10%
disabled · border 12%, label 38%

3. Text variant="text"

Tanpa container dan border, label --wui-color-primary, dengan padding inline yang lebih rapat (lihat tabel ukuran di bawah).

normal
.is-hover · layer primary 8%
.is-pressed · layer primary 10%
disabled · label 38%

4. Modifier yang tersedia

Varian dan ukuran bisa digabung bebas, mis. <button wuiButton variant="outlined" size="lg">. Ukuran tidak dijadikan contoh visual di halaman ini — cukup tabel berikut.

Varian warna · input variant

Nilai Kelas CSS Container Label State layer
filled (default) .wui-button--filled primary on-primary on-primary 8% / 10% di atas primary
outlined .wui-button--outlined transparan + border outline primary primary 8% / 10%
text .wui-button--text transparan (tanpa border) primary primary 8% / 10%

Ukuran · input size

Nilai Kelas CSS Tinggi Padding inline Padding text Tipografi label
sm .wui-button--sm 32px (2rem) 16px 8px label-medium
md (default) .wui-button--md 40px (2.5rem) 24px 12px label-large
lg .wui-button--lg 48px (3rem) 28px 16px label-large
xl .wui-button--xl 56px (3.5rem) 32px 20px title-medium

Angka di tabel ini berasal dari $wui-button-sizes di scss/abstracts/_tokens.scss — mengubah satu angka di sana mengubah kelas, CSS variable, dan directive sekaligus. Semua ukuran juga bisa ditimpa per pemakaian lewat style="--wui-button-height: 3.25rem".
