Usage

Modifier

Properti Keterangan
variant Mengatur bentuk tombol. Nilai: filled, text, outlined
size Mengatur ukuran tombol. Nilai: sm, md, lg, xl.
color Mengatur warna tombol. Nilai: default, primary, error.
size Mengatur posisi icon di dalam tombol. Nilai: start, end.
iconPos Mengatur posisi icon di dalam tombol. Nilai: start, end.
iconOnly Mengatur apakah isi dari tombol hanya icon atau tidak. Nilai: true, false.
