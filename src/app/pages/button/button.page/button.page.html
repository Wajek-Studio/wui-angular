WUI Button Specimen

Tombol @wajek/wui mengikuti Material 3 dengan tiga sumbu yang bisa digabung bebas: bentuk (variant: filled/outlined/text), peran warna (color: default/primary/error), dan ukuran (size: sm/md/lg/xl). Dipasang sebagai atribut pada <button> — atau <a> — native, sehingga disabled, type, dan perilaku form tetap milik browser.

State hover dan pressed dipaksa lewat class .is-hover / .is-pressed (pola yang sama dengan .is-dragged) supaya bisa dilihat tanpa menggerakkan mouse. Semua contoh memakai ukuran default md, dan contoh di bagian 1–4 memakai warna default (netral) karena itu perilaku bawaan tombol — perbandingan ketiga peran warna ada di bagian 7.

5. Modifier yang tersedia

Bentuk, warna, dan ukuran bisa digabung bebas, mis. <button wuiButton variant="outlined" color="error" size="lg">. Ukuran tidak dijadikan contoh visual di halaman ini — cukup tabel berikut.

Bentuk · input variant

Nilai Kelas CSS Container Label State layer
filled (default) .wui-button--filled peran warna aktif (--wui-button-container) --wui-button-content content 8% / 10% di atas container
outlined .wui-button--outlined transparan + border --wui-button-outline --wui-button-accent accent 8% / 10%
text .wui-button--text transparan (tanpa border) --wui-button-accent accent 8% / 10%

Peran warna · input color

Nilai Kelas CSS Peran warna Dipakai untuk
default (default) .wui-button--color-default default / on-default aksi netral — container diturunkan dari surface + on-surface
primary .wui-button--color-primary primary / on-primary aksi utama / brand
error .wui-button--color-error error / on-error aksi destruktif (hapus, batalkan)

color berlaku untuk ketiga varian: filled memakai peran sebagai container, outlined/text memakainya sebagai warna label. Semua nilainya token peran — menggantinya cukup lewat $wui-schemes di src/styles.scss, tanpa menyentuh komponen.

Sisi ikon · input iconPos

Nilai Kelas CSS Efek
start (default) .wui-button--icon-start ikon order: -1 → selalu di depan label
end .wui-button--icon-end ikon order: 1 → selalu di belakang label

Padding tombol simetris untuk semua varian — ikon tidak membuat sisi tempatnya lebih rapat. Yang diatur ikon hanya: posisinya (order), ukurannya (--wui-button-icon-size yang ikut ukuran tombol), dan jarak ke label (gap tombol = --wui-space-2 / 8px).

Angka di tabel ini berasal dari $wui-button-sizes di scss/abstracts/_tokens.scss — mengubah satu angka di sana mengubah kelas, CSS variable, dan directive sekaligus. Semua ukuran juga bisa ditimpa per pemakaian lewat style="--wui-button-height: 3.25rem".

Ukuran ikon dan line-height label sengaja memakai tangga yang sama (20/24/28/32px): kotak ikon dan kotak teks jadi sama tinggi, sehingga align-items: center menyejajarkan keduanya secara presisi — bukan sekadar mendekati. line-height dari peran tipografi (mis. label-large = 20px) sengaja dikalahkan oleh token tombol.
