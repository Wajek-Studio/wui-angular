Grid & Container

Sistem pembungkus terpusat responsif (.wui-container) dan kisi 12-kolom berbasis CSS Grid native (.wui-row & .wui-col-*) di @wajek/wui. Penggunaan CSS Grid murni (display: grid) dengan 12 kolom dan minmax(0, 1fr) membuat kolom anti-bocor pada konten panjang. Breakpoint menggunakan sistem mobile-first.

Daftar Class (Referensi)

A. Container

ClassKeterangan
.wui-container Memusatkan layout dan membatasi lebar maksimal proporsional (mentok 1200px di layar lebar).
.wui-container-fluid Selalu mengisi 100% lebar layar (tanpa batas maksimal).

B. Parent Grid (Wadah)

ClassKeterangan
.wui-row Memulai wadah CSS Grid dengan definisi 12 kolom merata.

C. Child Grid (Kolom)

ClassKeterangan
.wui-col Setara dengan rentang (span) 1 kolom.
.wui-col-[1..12] Ukuran kolom statis di semua ukuran layar (misal: .wui-col-6 memakan 6 kolom).
.wui-col-[bp]-[1..12] Ukuran kolom yang berlaku mulai breakpoint bp (sm, md, lg, xl, xxl) ke atas.

D. Gap (Jarak Antar Sel)

ClassKeterangan
.wui-gap-row-[0..5] Mengatur jarak vertikal antar baris untuk semua ukuran layar.
.wui-gap-row-[bp]-[0..5] Mengatur jarak vertikal antar baris mulai breakpoint bp ke atas.
.wui-gap-col-[0..5] Mengatur jarak horizontal antar kolom untuk semua ukuran layar.
.wui-gap-col-[bp]-[0..5] Mengatur jarak horizontal antar kolom mulai breakpoint bp ke atas.
