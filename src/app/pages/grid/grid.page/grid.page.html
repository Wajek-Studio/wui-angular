Container, Row/Col & Grid

Sistem pembungkus terpusat responsif (.wui-container), sistem tata letak 12-kolom (.wui-row & .wui-col-*), serta utilitas murni CSS Grid (.wui-grid & .wui-grid-col-*) di @wajek/wui. Keduanya memanfaatkan CSS Grid murni (display: grid) yang modern dan tangguh.

1. Container (Pembungkus Halaman)

ClassKeterangan
.wui-container Memusatkan layout dan membatasi lebar maksimal proporsional.

2. Row & Column (12-Column Layout)

ClassKeterangan
.wui-row Memulai wadah tata letak dengan definisi 12 kolom merata.
.wui-col Setara dengan rentang (span) 1 kolom.
.wui-col-[1..12] Ukuran kolom statis di semua ukuran layar (misal: .wui-col-6 memakan 6 kolom).

3. Responsive Breakpoints (Row/Col)

Class BreakpointKeterangan
.wui-col-[bp]-[1..12] Ukuran kolom yang berlaku mulai breakpoint bp (sm, md, lg, xl, xxl) ke atas.

4. CSS Grid Utilities & Span

Class Utilitas GridKeterangan
.wui-grid Mengaktifkan display: grid pada wadah.
.wui-grid-inline Mengaktifkan display: inline-grid pada wadah.
.wui-grid-col-[1..12] Menentukan jumlah template kolom di wadah grid untuk semua ukuran layar.
.wui-grid-col-[bp]-[1..12] Menentukan jumlah template kolom di wadah grid mulai breakpoint bp.

5. Pengaturan Gap

Class GapKeterangan
.wui-gap-row-[0..5]
.wui-gap-col-[0..5]		 Mengatur jarak baris/kolom untuk semua layar.
.wui-gap-row-[bp]-[0..5]
.wui-gap-col-[bp]-[0..5]		 Mengatur jarak baris/kolom mulai breakpoint bp ke atas.
