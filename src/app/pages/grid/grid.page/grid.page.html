Grid & Container

Sistem pembungkus terpusat responsif (.wui-container) dan kisi 12-kolom berbasis CSS Grid native (.wui-row & .wui-col-*). Penggunaan CSS Grid murni (display: grid) dengan minmax(0, 1fr) membuat kolom anti-bocor pada konten panjang.

1. Container (Pembungkus Halaman)

ClassKeterangan
.wui-container Memusatkan layout dan membatasi lebar maksimal proporsional (mentok 1200px di layar lebar).
.wui-container-fluid Selalu mengisi 100% lebar layar (tanpa batas maksimal).

2. Basic 12-Column Grid

ClassKeterangan
.wui-row Memulai wadah CSS Grid dengan definisi 12 kolom merata.
.wui-col Setara dengan rentang (span) 1 kolom.
.wui-col-[1..12] Ukuran kolom statis di semua ukuran layar (misal: .wui-col-6 memakan 6 kolom).

3. Responsive Breakpoints

Class BreakpointKeterangan
.wui-col-[bp]-[1..12] Ukuran kolom yang berlaku mulai breakpoint bp (sm, md, lg, xl, xxl) ke atas.

4. Pengaturan Gap

Class GapKeterangan
.wui-gap-row-[0..5]
.wui-gap-col-[0..5]		 Mengatur jarak baris/kolom untuk semua layar.
.wui-gap-row-[bp]-[0..5]
.wui-gap-col-[bp]-[0..5]		 Mengatur jarak baris/kolom mulai breakpoint bp ke atas.
