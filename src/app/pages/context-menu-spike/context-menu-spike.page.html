Spike F0 — context menu

Harness pengukuran untuk docs/planning/wui-context-menu-plan.md (§7 F0, hasil masuk ke §9). Menunya memakai directive CDK apa adanya ([cdkContextMenuTriggerFor] + cdkMenu + cdkMenuItem), tanpa pembungkus wui-*; strategi gulir ditimpa jadi block() (keputusan N5). CDK tidak mengirim CSS menu sama sekali, jadi gaya panel di bawah ini milik harness — bukan angka desain. 

{{ jejakTeks() }}

1. Pemicu div (tidak fokusable)

Klik kanan di dalam kotak. Yang dicari: panel muncul di titik penunjuk, item pertama difokus, dan saat menu tertutup fokus kembali ke elemen pemicu (yang tidak fokusable ini akan jadi catatan tersendiri).

klik kanan di sini

2. Pemicu button (fokusable)

Sama, tapi pemicunya tombol: fokus harus bisa kembali ke tombol itu saat menu tertutup.

3. Daftar panjang (gulir di dalam panel)

40 item, panel dibatasi max-height: 240px. Yang dicari: roda gulir di atas panel menggulir panelnya, sementara halaman tetap terkunci.

klik kanan untuk daftar 40 item

4. Item dinamis selagi menu terbuka

Kaitnya window.spikeTambah() / window.spikeHapus() (dipanggil dari luar) — tombol di halaman tidak bisa dipakai karena mengkliknya adalah klik di luar panel. Yang dicari: setelah daftar berubah, panah tetap bekerja pada daftar terbaru.

klik kanan (daftar {{ daftarDinamis().length }} item)

5. Buka paksa di sudut kanan-bawah

CdkContextMenuTrigger.open() di 6px dari tepi kanan & bawah. Yang dicari: panel di-push ke dalam jendela (utuh), bukan keluar layar.

klik kanan di sini

6. RTL

Kotak dir="rtl": arah start/end panel harus ikut terbalik (offset 2px bawaan CDK ada di sisi yang berbeda).

klik kanan di kotak RTL

7. Di dalam dialog (focus trap menyala)

Yang dicari: menu tetap terbuka (trap dialog tidak merebut fokus itemnya), panel tampak di atas dialog, dan Esc menutup menu saja.

Ruang kosong di bawah ini hanya supaya halaman cukup tinggi untuk membuktikan gulirnya terkunci: roda gulir di luar panel harus tidak menggeser window.scrollY selama menu terbuka.

@for (baris of panjang; track baris) { }
@for (baris of daftarDinamis(); track $index) { }

Klik kanan di kotak; lalu coba Esc sekali (menu saja yang tertutup) dan sekali lagi (dialognya tertutup).
