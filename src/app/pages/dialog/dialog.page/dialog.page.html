WUI Dialog

Dialog modal dari WuiDialogService. Mesinnya @angular/cdk, tapi yang dipakai aplikasi hanya WuiDialogRef, WuiDialogOptions, dan WUI_DIALOG_DATA — tipe CDK tidak perlu diimpor. Isi dialog dirender ke document.body, terpisah dari page stack yang tinggal di dalam <wui-app>.

Yang datang gratis dari CDK: focus trap, ESC menutup, klik backdrop menutup, scroll halaman diblokir, fokus kembali ke tombol pemicu, dan role="dialog" + aria-modal="true". Yang ditambahkan wui: permukaan .wui-dialog, backdrop dari token --wui-overlay-color, dan urutan lapisan lewat --wui-z-dialog (selalu di atas page stack).

1. Dari komponen — open()

Hasilnya bertipe: open<boolean>(HapusDialog, { data }) → await ref.result bernilai boolean, atau undefined kalau ditutup lewat ESC/backdrop. Komponen dialog mengambil datanya lewat injectDialogData() dan menutup dirinya lewat inject(WuiDialogRef).

Hasil: {{ hasilKomponen() }}

2. Dari <ng-template> — openTemplate()

Konteks template memakai kontrak CDK: let-data berisi options.data. Karena tidak ada komponen pemilik, ref-nya dipegang halaman (openTemplate() tetap mengembalikan WuiDialogRef).

Hasil: {{ hasilTemplate() }}

3. Alert — role="alertdialog" + disableClose

ESC dan klik backdrop dimatikan, jadi hanya tombol di dalam dialog yang bisa menutupnya — perilaku yang diharapkan untuk dialog sistem. Penampilan alert khusus (ikon, warna, tata letak) belum ada; di v1 ini baru peran ARIA-nya.

4. Dialog sistem — alert()

Untuk pesan yang tidak punya tata letak sendiri (error API, konfirmasi singkat). Isinya datang sebagai data — tidak ada komponen atau <ng-template> baru di sisi aplikasi. Hasilnya index tombol (0 … n-1), atau null kalau ditutup tanpa memilih.
