Modifier

Properti Keterangan
data Data yang diteruskan ke komponen/template via WUI_DIALOG_DATA atau let-data
role 'dialog' (default) atau 'alertdialog' — memengaruhi peran ARIA yang diumumkan ke screen reader
disableClose true → ESC dan klik backdrop tidak menutup dialog. Wajib dipakai bersama role="alertdialog"
ariaLabelledBy ID elemen judul di dalam dialog untuk screen reader (aria-labelledby)
ref.result Promise yang resolve saat dialog ditutup dengan nilai dari close(result)
ref.close(value?) Tutup dialog dan kirim nilai ke ref.result. Tanpa nilai → resolve undefined
