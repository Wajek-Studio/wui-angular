WuiDialogRef

result: Promise<T | undefined>

Promise yang resolve saat dialog ditutup. Nilainya dari close(value), atau undefined jika ditutup tanpa nilai.

close(value?: T): void

Tutup dialog dan kirim nilai ke result.

WuiDialogOptions

Properti Keterangan
data Data yang diteruskan ke komponen/template via WUI_DIALOG_DATA atau let-data
role 'dialog' (default) atau 'alertdialog'
disableClose true → ESC dan klik backdrop tidak menutup dialog
ariaLabelledBy ID elemen judul di dalam dialog untuk aria-labelledby
dismissible Khusus alert(). false → sama dengan disableClose: true
